# Tapas.io Test Automation Project

이 프로젝트는 Tapas.io 서비스의 핵심 기능(검색, 에피소드 이동, 내비게이션)을 Playwright 기반으로 자동화한 QA 테스트 프로젝트입니다. 5년 차 QA 엔지니어의 관점에서 **유지보수성(Maintainability)**, **신뢰성(Reliability)**, 그리고 **기능적 깊이(Functional Depth)**를 최우선으로 고려하여 설계되었습니다.

## 🛠 주요 특징
- **효율적인 자동화 구조**: AI와 함께 페이지 단위로 요소와 동작을 분리(POM)하여, 추후 UI 변경 시에도 코드 수정이 간편하도록 유지보수성을 높였습니다.
- **실전형 테스트 전략**: 단순한 화면 이동 확인을 넘어, 에피소드 정렬 기능이나 첫 에피소드 이동 시 버튼 비활성화 확인 등 **실제 기능이 정상적으로 동작하는지 검증**하는 데 집중했습니다.
- **Flaky 테스트 방지**: 네트워크 지연 등에 테스트가 깨지지 않도록, Playwright의 Auto-waiting 기능을 적극적으로 활용하여 테스트 실행의 안정성을 확보했습니다.

## 🧪 테스트 시나리오 구성

| 시나리오 분류 | 검증 항목 |
| :--- | :--- |
| **핵심 유저 흐름** | 검색, 작품 상세 이동, 에피소드 선택, 내비게이션 |
| **기능적 Edge Case** | 에피소드 정렬 동적 변경 검증 |
| **경계 값 테스트** | 첫 에피소드 진입 시 '이전 화' 버튼 비활성화 상태 확인 |

## 💡 효율적인 테스트
로그인 기능은 보안(캡챠) 문제로 자동화가 어려웠습니다. 그래서 **로그인 없이도 수행할 수 있는 가장 중요한 사용자 흐름(작품 찾고 읽기)**에 집중하여 자동화 효율을 높였습니다.

---

## 🧠 AI 활용

본 프로젝트는 Gemini를 활용한 AI-assisted development 방식으로 구현했습니다. 테스트 대상 시나리오와 자동화 범위, 프로젝트 구조 및 POM 적용 방향을 직접 정의하고, Gemini를 활용해 Playwright/TypeScript 코드 구현을 보조받았습니다. 생성된 코드에 대해서는 테스트 실행 및 결과 검토를 통해 QA 관점에서 검증하고 수정했습니다.

## 🛠 실행 방법

```bash
# 의존성 설치
npm install

# 모든 테스트 실행
npx playwright test

# 리포트 확인
npx playwright show-report
```
