# Tapas Test Automation Project

이 프로젝트는 Tapas 서비스의 비로그인 핵심 흐름(검색, 작품 선택, 에피소드 리더 진입)을 Playwright 기반으로 자동화한 QA 포트폴리오입니다. QA 엔지니어의 관점에서 **유지보수성(Maintainability)**, **신뢰성(Reliability)**, **실제 기능 동작 및 경계 조건** 검증을 중심으로 설계했습니다.

## 🛠 주요 특징
- **재사용 가능한 자동화 구조**: POM과 Playwright fixture로 페이지 객체 생성·시작 상태를 분리했습니다.
- **의미 있는 검증**: URL뿐 아니라 리더 제목, 정렬 후 목록 갱신, 이전/다음 버튼 상태를 확인합니다.
- **테스트 불안정성 대응**: 고정 시간 대기 대신 UI 상태 변화를 기다리고, 쿠키 배너를 공통으로 처리합니다.
- **환경 전환 준비**: `BASE_URL` 환경변수로 대상 환경을 바꾸고, CI에서는 단일 워커와 1회 재시도를 사용합니다.

## 🧪 테스트 시나리오 구성

| 시나리오 분류 | 검증 항목 |
| :--- | :--- |
| **핵심 유저 흐름** | 홈 로드, 검색 결과, 작품 상세 이동, 에피소드 리더 진입 |
| **기능 검증** | 정렬 후 첫 에피소드 제목 갱신, 리더 제목과 다음 화 버튼 상태 |
| **경계 조건 검증** | 첫 에피소드에서 '이전 화' 버튼 비활성화 상태 |

## 💡 효율적인 테스트
로그인 기능은 보안(캡챠) 문제로 자동화가 어려웠습니다. 그래서 **로그인 없이도 수행할 수 있는 가장 중요한 사용자 흐름(작품 찾고 읽기)**에 집중하여 자동화 효율을 높였습니다.

## 🧠 AI 활용

본 프로젝트는 Gemini를 활용한 AI-assisted development 방식으로 구현했습니다. 테스트 대상 시나리오와 자동화 범위, 프로젝트 구조 및 POM 적용 방향을 직접 정의하고, Gemini를 활용해 Playwright/TypeScript 코드 구현을 보조받았습니다. 생성된 코드에 대해서는 테스트 실행 및 결과 검토를 통해 QA 관점에서 검증하고 수정했습니다.

## 🛠 실행 방법

```bash
# 의존성 설치
npm install

# 모든 테스트 실행
npx playwright test

# 리포트 확인
npx playwright show-report
```

```bash
# 타입 검사
npm run typecheck

# 브라우저를 보며 실행
npm run test:headed

# Playwright UI 모드
npm run test:ui
```

## 테스트 범위 메모

Tapas의 현재 비로그인 공개 화면에서는 리더의 `Next` 컨트롤이 표시되지만, 자동화 실행 환경에서 다음 에피소드 전환이 일관되게 발생하지 않습니다. 따라서 이 포트폴리오는 해당 컨트롤의 **표시 및 활성 상태**까지를 검증 범위로 두었습니다. 로그인·권한이 필요한 실제 에피소드 전환은 인증된 테스트 계정과 별도 테스트 데이터가 준비된 뒤 확장하는 것이 적절합니다.
